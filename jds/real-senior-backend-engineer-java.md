## Job Summary

As a Senior Backend Engineer, you will report to the Vice President of Engineering and be a key member of Real's R&D team. You will operate in an AI-first environment leveraging tools like Claude Code to translate product ideas into production-ready systems. You will help lead the overall technical vision for backend work, implementing features, fixing bugs, and making improvements across Java Spring microservices. You would also drive adoption of AI-assisted development practices within the backend engineering team.

This role is about:

- Designing scalable systems
- Validating and owning AI-assisted code
- Driving technical excellence across the team

## What You'll Do

- Collaborate with engineers through pairing sessions, code reviews, and weekly Dev Chats.
- Mentor and lead junior engineers in software engineering methodology, design, and best practices.
- Work with product and feature owners to understand requirements and see them through to execution and deployment.

- Extensive experience with Java 17+ (migrating toward Java 21), Spring Boot 3.x, JPA/Hibernate 6, and SQL relational databases.

- Collaborative attitude, willingness to teach and learn.

## AI-Assisted Development

Real operates in an AI-first engineering environment. Backend engineers use AI coding assistants and agentic developer tools every day, wired into internal systems.

- Hands-on experience with AI coding assistants such as Claude Code, Cursor, Codex, or similar.
- Familiarity with agentic / CLI-based AI workflows and MCP integrations that connect AI tools to internal systems such as GitHub, Datadog, issue tracking, and SonarQube.
- Experience applying AI to accelerate code review, test generation, and documentation, not just code completion.
- Ability to critically evaluate generated code, identify incorrect or suboptimal outputs, and refactor AI-generated code for production readiness.
- Strong judgment on when to use AI versus manual implementation, trade-offs between speed and correctness, and validating and owning AI-assisted code before shipping.
- Strong test coverage supports continuous delivery with multiple deploys per day.
